DATA PROTECTION

Privacy & data practices.

Plain-language guidance for how the Pen Tube architecture handles creator data.

What we collect

Account details needed for authentication, such as email and display name. Saved Creator Vault items contain the generated type, title, prompt/output, metadata, and timestamps.

Why we collect it

Authentication data supports account access. Vault data is stored so you can reopen and manage your own creator work.

Firebase

Firebase Authentication handles login. Firestore stores user profiles and vault records. Firestore Security Rules are designed so a signed-in user can only access their own vault.

Gemini

AI generation requests are sent through a server-side Firebase callable function so the Gemini API secret is not shipped to the browser. Provider policies and quotas apply.

YouTube API

Optional YouTube research requests are routed through a server-side function and are quota-controlled. Search results are research signals; the application does not label them as an official “trending keyword score.”

Pollinations

Thumbnail preview generation uses the Pollinations image endpoint as an optional preview service. Its own service terms and processing practices apply.

Files

The current reference-image dropzone uses local browser preview only. Files are not automatically uploaded. A future Storage integration can be added behind explicit user action.

Deletion

Users can delete individual vault records. A full account-deletion workflow should also remove the profile and remaining vault data before the account is deleted.

Security

Pen Tube uses reasonable technical safeguards such as authenticated access, Firestore rules, server-side secrets, input validation, and error handling. No online system can guarantee absolute security.

Cookies & local storage

The app avoids advertising trackers by default. Firebase Authentication may use browser persistence mechanisms required for sign-in. Do not add third-party analytics without updating this page.
